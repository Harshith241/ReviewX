# ReviewX
 A product review aggregator that collects all the reviews from multiple sites and displays the merged review with AI summarization.   

## Features  
 Web Scraping (Amazon, Best Buy, etc.)  
 AI-powered Sentiment Analysis & Review Summarization  
 Search & Filter for easy navigation  
 User-friendly web interface  

## Tech Stack  
- **Frontend:** React.js / Next.js  
- **Backend:** FastAPI / Node.js  
- **Database:** MongoDB / PostgreSQL  
- **AI:** OpenAI GPT / Hugging Face BERT  
- **Scraping:** BeautifulSoup, Selenium
